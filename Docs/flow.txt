QUAN TRỌNG: Price được quản lý theo VEHICLE MODEL (không phải Vehicle Type)
→ Mỗi mẫu xe có bảng giá riêng (VD: Toyota Vios ≠ Honda City)

┌─────────────────────────────────────────────────────────────────────────┐
│  PRICE STRUCTURE (3 LOẠI GIÁ)                                            │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                           │
│  1. BASE PRICE (Giá ngày thường)                                         │
│     • Đơn giá cơ bản cho 1 ngày thuê xe                                  │
│     • VD: 500.000 VNĐ/ngày                                               │
│                                                                           │
│  2. MONTH PRICE (Giá tháng - Thuê dài hạn)                               │
│     • Công thức: Base Price × 30 × monthMul                              │
│     • monthMul: Hệ số tháng (VD: 0.85 = giảm 15%)                        │
│     • VD: 500.000 × 30 × 0.85 = 12.750.000 VNĐ/tháng                     │
│                                                                           │
│  3. PEAK PRICE (Giá ngày lễ)                                             │
│     • Công thức: Base Price × peakMul                                    │
│     • peakMul: Hệ số lễ (VD: 1.5 = tăng 50%)                             │
│     • VD: 500.000 × 1.5 = 750.000 VNĐ/ngày lễ                            │
│                                                                           │
└─────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│  LOGIC TÍNH GIÁ THEO SỐ NGÀY THUÊ                                        │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                           │
│  CASE 1: Thuê < 30 ngày → Tính chi tiết theo từng ngày                   │
│  ────────────────────────────────────────────────────────────────────── │
│    Total = (Số ngày thường × Base Price) +                               │
│            (Số ngày lễ × Peak Price)                                     │
│                                                                           │
│    VD: Thuê từ 1/2 đến 5/2 (5 ngày, có 2 ngày lễ)                        │
│        → 3 ngày thường: 3 × 500.000 = 1.500.000                          │
│        → 2 ngày lễ: 2 × 750.000 = 1.500.000                              │
│        → TỔNG: 3.000.000 VNĐ                                             │
│                                                                           │
│  CASE 2: Thuê ≥ 30 ngày → Áp dụng giá tháng cho TOÀN BỘ                  │
│  ────────────────────────────────────────────────────────────────────── │
│    Total = (Base Price × monthMul × Số ngày thuê)                        │
│    • KHÔNG tách lẻ ngày lễ                                               │
│    • Khuyến khích thuê dài hạn                                           │
│                                                                           │
│    VD: Thuê 35 ngày (có 5 ngày lễ trong đó)                              │
│        → KHÔNG tính: (30 ngày × giá tháng) + (5 ngày × giá lễ)          │
│        → MÀ TÍNH: 500.000 × 0.85 × 35 = 14.875.000 VNĐ                   │
│                                                                           │
└─────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│  QUẢN LÝ NGÀY LỄ (HOLIDAY CONFIG)                                        │
├─────────────────────────────────────────────────────────────────────────┤
│  • Admin tự cấu hình ngày lễ trong năm                                   │
│  • Bảng: HolidayConfig                                                   │
│    - HolidayName: "Tết Nguyên Đán 2026"                                  │
│    - StartDate: 2026-01-28                                               │
│    - EndDate: 2026-02-03                                                 │
│    - IsActive: true                                                      │
│  • Hỗ trợ thêm/xóa/sửa ngày lễ realtime                                  │
└─────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
